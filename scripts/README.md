# Automation Scripts

This directory will contain sanitised Microsoft Graph PowerShell automation created during the project.

Planned scripts:

- Joiner workflow from validated CSV input
- Department and group assignment
- Licence assignment with availability checks
- Mover workflow
- Leaver workflow with session revocation and access removal
- Reporting and validation helpers

Scripts will include error handling, least-privilege permission requirements, safe defaults, dry-run support where practical, and documentation of expected inputs and outputs. No tenant-specific identifiers or credentials will be committed.
